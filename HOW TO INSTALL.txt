Call Track (Training) — Installation Guide
==========================================

STEP 1 — Docker Desktop
  If you already run Call Track (Production), Docker Desktop is already installed.
  Just make sure Docker Desktop is running (whale icon in your taskbar).
  If not installed, download from: https://www.docker.com/products/docker-desktop

STEP 2 — Run the setup (one time only)
  Right-click the file called "setup.ps1" in this folder
  Choose "Run with PowerShell"
  If Windows asks "Do you want to allow this app..." click Yes
  Wait for it to finish — it takes about 30 seconds

STEP 3 — You are done!
  Two dedicated training shortcuts have been created on your Desktop:
  - "Start Call Track (Training)" — double-click to open the training app (Port 4000)
  - "Stop Call Track (Training)"  — double-click to shut down training

  Note: Your existing "Start Call Track" and "Stop Call Track" shortcuts are NOT touched or replaced.
  Both instances can run at the same time!

  The FIRST time you start the app it will take 3-5 minutes
  to build itself. After that it starts in about 10 seconds.

Your training login details:
  Initial secure passwords are automatically generated during setup.
  Open the "SEED_CREDENTIALS.txt" file in this folder to view your credentials:
    - Admin:      admin-trn@calltrack.local       -> (see SEED_CREDENTIALS.txt)
    - Freelancer: freelancer-trn@calltrack.local  -> (see SEED_CREDENTIALS.txt)

  Notice the amber banner across the top:
  "⚠️ TRAINING ENVIRONMENT — Port 4000"
  This confirms you are safely working in the training sandbox.
